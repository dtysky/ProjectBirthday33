# G4 原始参考素材准备表

更新时间：2026-08-06

## 用途与范围

这份表只用于准备 G4 美术生成所需的真实照片、视频、录屏和旧作原件，不是最终 CG 清单。

- G4 当前规划 27 个镜头包，需要 29 组正式来源素材：`SRC-04`、`SRC-05A` 至 `SRC-05Q`（不含已取消的 `SRC-05H`）、`SRC-06A` 至 `SRC-06D`、`SRC-07A` 至 `SRC-07D`、`SRC-08A` 至 `SRC-08D`。
- `SRC-05M`、`SRC-05N`、`SRC-05O` 已有 Kairos 文件索引，先确认原文件可访问，不必重复上传。
- `SRC-05E`、`SRC-05K`、`SRC-05P` 必须各自选定一张最终主参考。它们已经按一张 CG 设计，不再拆成多图。
- 除正式来源外，还需准备 6 组跨镜头连续性参考，见文末“共用连续性素材”。

## 放置与命名

推荐按编号放入 Git 已忽略的本地目录；来不及分类时也可以全部放进 `art/references-local/inbox/`，保留原文件名，我后续再整理：

```text
art/references-local/g4/
├── 00-common/
├── SRC-04/
├── SRC-05A/
├── ...
└── SRC-08D/
```

每个目录保留原始文件名，并补一个简单的 `notes.txt`，记录：

- 拍摄地点与日期；
- 推荐使用的照片文件名；
- 视频推荐时间点，例如 `00:31-00:38`；
- 画面中的人物分别是谁；
- 是否允许露出正脸、车牌、导航或屏幕内容。

## 素材交付标准

- 优先提供原图、原视频或相机导出的高质量文件，不提供社交平台压缩图、滤镜图、拼图和二次截图。
- 不要先裁成 16:9。竖图、全景图和视频都可以保留原始画幅，后续根据字幕安全区重新构图。
- 每个现实地点至少需要一张环境全貌，以及一张能判断人物、车辆或设备比例的画面。只有漂亮空镜通常不够。
- 视频不用提前抽帧，但必须标出推荐时间点；延时素材保留完整原文件。
- 车牌、同行者正脸、导航地址和工作屏幕可以在最终画面中脱敏，但原始参考不要为了脱敏裁掉空间关系。
- 表中“主参考”指最终 CG 的构图基准。辅助素材只能补人物、车辆、材质和天气，不能把多个地点人工拼成一张。

批次说明：`P0` 为开始生成前必须锁定；`P1` 为对应镜头生成前必须具备；`P2` 可在家中补拍或重建，放在旅行素材之后准备。

## 推荐准备顺序

1. 先准备 `SRC-04`、三个最终主参考 `SRC-05E／05K／05P`、金字塔与卡牌 `SRC-05L`。
2. 再集中准备子梅垭口 `SRC-07A` 至 `SRC-08D`，同时整理三名同行者和当次装备，保证人物、车辆、积雪和天光连续。
3. 准备破晓、腾格里、国内路线与埃及素材 `SRC-05B` 至 `SRC-05L`。
4. 确认 Kairos 中 `SRC-05M／05N／05O` 的原文件和推荐时间点，再补 `SRC-05A／05Q`。
5. 最后在家中集中补拍 `SRC-06A／06C／06D`；`SRC-06B` 从已有旅行中选择一处真实落空现场。

每准备完一组，可以直接在本表“完成”列把 `☐` 改成 `☑`，并在最后一列写入实际文件名或目录。
