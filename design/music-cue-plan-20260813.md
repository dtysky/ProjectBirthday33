## 当前结论

《三十三》是由玩家推进文本的叙事游戏，不按固定时长播放的电影。运行时配乐因此全部采用**可无限循环的状态音乐**：每条音乐维持同一个叙事状态，但内部可以反复经历铺开、抬升、呼吸和回落。剧情变化由 `story.json` 的台词 ID 触发切换、交叉淡化、硬切或停止，不能依靠“第 35 秒进入全曲唯一高潮”之类的内部时间线。

全章不需要无差别铺满音乐，但也不再设置 35%—40% 的低覆盖目标。当前是由玩家控制阅读节奏的视觉小说，音乐应在一个完整叙事段内保持连续；环境声独占和真正静默只用于明确的结构断点。实机初始目标可落在约 65%—75% 的 BGM 覆盖，但最终以场景是否成立为准，不以百分比验收。配乐承担三件事：

1. 让同一个问题在不同章节中重新出现。
2. 标记人物真正发生判断变化的时刻。
3. 在 G4、G5 把此前经历收束到“停止延期”，但不把结尾写成胜利凯歌。

本表只规划配乐，不生成或导入音频，也不改动台词。入点、状态切换与出点都绑定台词 ID；玩家在任一句停留多久，都不会错过音乐中的“规定时刻”。

## 游戏播放前提

- 每条运行时 BGM 都必须能在当前状态中无限循环；60 秒或 120 秒只是平台**原始素材**长度，不是剧情演出长度，也不等于最终 Loop 长度。
- 生成器会在时长边界强制截断，不能靠一句 `seamless loop` 让原始输出天然无缝。所有源文件先丢弃静音片头和截断尾部，再从中段选择循环点并制作交叉淡化。
- 单条 Loop 不设置一次性的开场、高潮、结尾和淡出，但允许明显的循环性情绪波形。一次抒情上扬可以在 Loop 内反复发生，只要它能自然回到呼吸段，而不是单向走向终点。
- 每个 Cue 先按剧本需要独立生成和审查；试听后可以独立保留，也可以复用旧主题、制作变奏或合并。不能仅凭段落长短预先决定必须拆开或必须共用同一首。
- 音乐切换默认由台词 ID 触发，使用双播放器交叉淡化；叙事断裂处才使用硬切。
- 环境声、音乐性声音设计和 BGM 分轨播放。风、海浪、车辆、办公室、检索提示等不烘焙进 Loop。
- 章节选择器从段落中间进入时，直接恢复该台词所属的音乐状态；不必等待一段线性 Cue 从头发展。
- 原始素材优先生成 48 kHz／24-bit WAV。60 秒源文件通常得到约 44—52 秒成品 Loop，120 秒源文件通常得到约 95—110 秒成品 Loop；运行时再转换为经过实机验证的 Ogg。MP3 只用于审听。

## 声音层级

运行时把三类声音分开管理：

- **环境声**：空间真实存在的声音，如空调、键盘、道路、风雪和海浪。它负责让经历成立。
- **音乐性声音设计**：介于环境与配乐之间的持续音、谐波和处理过的现场声。它负责场景与章节间的暗线。
- **配乐 Loop**：能被听成旋律、和声或节奏组织的部分。它只在关键判断处进入。

环境声不能因为配乐进入而消失；音乐应像从空间里长出来，而不是覆盖画面。

## 情绪纵深与循环方式

- 低潮 Cue 也需要内部对比：干燥段可以短暂聚拢成旋律，再重新散开。
- 抒情 Cue 不维持平直“氛围床”，而采用可重复的波形：主题出现 → 配器抬升 → 留出呼吸 → 回到可再次进入的位置。
- G3 是第一次允许情感被说清；G4 是空间和行动真正打开；G5 则让此前主题获得最完整、最向上的形态。三者必须听出递进。
- “不胜利”不等于“不上扬”。终章可以明亮、辽阔、有力量，只需保留现实代价与开放结尾，不落英雄式终止。

## 运行时接入原则

- 音频总线至少拆为 `Voice`、`Ambience`、`SFX`、`Music`；设置中的主音量控制它们的父总线。
- `Music` 使用两个播放器。场景内普通状态切换交叉淡化 1.5—3 秒；换章另走“预淡出—章节卡—新场景留白—延迟淡入”的长衔接。
- 每个台词 ID 映射为 `keep`、`start`、`crossfade`、`fade_out` 或 `hard_stop`，不在画面脚本中等待音乐播放到某秒。
- 配乐在对白出现时默认降低约 2—4 dB，关键停顿处允许恢复；环境声只做必要的频段与响度整理。
- 生成原始文件不得直接导入。先在稳定中段找到两处和声、节奏与尾响相近的候选点，做 2—6 秒等功率交叉淡化，再导出独立 Loop 母版。
- 循环点必须在 Godot 实机连续播放至少五轮审查：检查接缝爆音、编码空隙、尾响叠加、节拍错位与动态跳变。
- Cue 状态写入存档。读取到段落中间时恢复该台词所属状态；可从 Loop 起点开始，也可恢复播放位置，但不能触发一次性“开场演出”。
- 若某个自动镜头需要一次性的命中声、低频落点或转场尾音，把它做成 `SFX` 或 `music stinger`，不得破坏底层 BGM 的循环结构。
